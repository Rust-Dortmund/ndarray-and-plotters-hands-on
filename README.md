# README

## Installation of mdBook

```
cargo install mdbook
```

## Cloning the repository

```
git clone https://github.com/Rust-Dortmund/ndarray-and-plotters-hands-on
```


## Building and opening the book

```
cd ndarray-and-plotters-hands-on
cd Error-Bars-and-Geometric-Visualizations-in-Rust-using-ndarray-and-plotter-rs
mdbook build
mdbook serve --open
```
