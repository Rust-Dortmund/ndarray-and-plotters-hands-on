# Running snipptes

To run the code snippets there are two options:

Open a terminal, start either
- `evcxr`
    - opens a repl in the terminal
- `jupyter notebook`
    - opens a jupyter notebook in the browser
	- click the button *new* on the upper right
	- choose **rust**

Copy the following code snipptes and paste them to the repl or to a cell of the notebook.
